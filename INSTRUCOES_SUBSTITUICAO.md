# Pacote visual final

1. Apague do repositório os arquivos antigos `assets/claro-report-theme.css`, `assets/claro-report-theme.js`, `assets/claro-visual-aprovado.css` e `assets/claro-visual-aprovado.js`, se existirem.
2. Envie TODO o conteúdo desta pasta para a raiz do repositório.
3. Confirme a substituição de todos os HTMLs, incluindo `index.html` e `visualizador_relatorio.html`.
4. Aguarde o GitHub Pages concluir o deploy e faça Ctrl+F5.

O tema está embutido em cada HTML, portanto não depende de novos assets para aparecer.
